# 璀璨宝石

Windows 离线桌游，一名玩家与 1–3 名电脑对手对战。通过收集宝石、购买发展卡和接待贵族获得威望，支持简单、普通、困难三档 AI。

[下载便携版](https://github.com/GodBook/brilliant-gems/releases/latest) · [游戏说明书](游戏说明书.md)

当前版本为 **1.1.0**，使用 Electron、React 和 TypeScript 开发。

## 下载与运行

从 Releases 下载 `Brilliant-Gems-Portable-x64.exe` 后双击运行，无需安装。首次显示窗口前需要解压运行资源，可能等待约 20–30 秒，实际时间取决于设备。

- Windows 10/11，x64。
- 最低窗口尺寸 1280 × 720，建议使用更高分辨率。
- 不需要网络，不包含账号、遥测或自动更新。

便携版尚无代码签名，Windows SmartScreen 可能提示“未知发布者”。请核对下载来源。

## 玩法

项目实现经典基础版的核心规则：90 张发展卡、10 位贵族、2–4 人资源配置、黄金替代、保留牌、筹码上限和同分判定。开局可选择自己的座位、各 AI 难度及 5–50 点目标威望，默认 15 点。

每回合选择一项行动：

1. 拿取三种不同颜色的宝石；不足三种时，拿取仍有库存的颜色。
2. 拿取两枚同色宝石，操作前该颜色至少有四枚。
3. 购买市场牌或自己的保留牌，永久折扣先抵扣成本，不足部分可用黄金支付。
4. 保留一张市场牌或从牌库暗抽，每人最多三张；有黄金时同时拿取一枚。

行动后处理筹码超限归还、贵族选择和终局检查。任意玩家达到目标威望后，补齐当前轮次，再比较总威望；同分时购买发展卡较少者获胜，仍相同则共同获胜。

| 玩家数 | 每种彩色筹码 | 黄金 | 贵族 |
| --- | --- | --- | --- |
| 2 | 4 | 5 | 3 |
| 3 | 5 | 5 | 4 |
| 4 | 7 | 5 | 5 |

完整规则和操作见[游戏说明书](游戏说明书.md)。

## 电脑对手与设置

简单 AI 从合法行动中选择，对可以立即购买的牌给予基础偏好。普通 AI 使用启发式评分，考虑威望、成本、折扣、目标牌和贵族进度。困难 AI 在此基础上进行隐藏信息采样和受限搜索，只使用公开信息及自己的隐藏信息。

AI 行动动画可选择 1x、2x 或“立即”。背景声音和操作音效可以分别调整，也可开启全屏或减少动态效果。

设置中可调整对手筹码、保留牌和可购牌提示的显示。这些选项只改变界面，不影响规则和 AI 可见的信息。

## 存档

每次有效行动后自动保存，从主菜单可继续游戏。损坏或不兼容的存档会提示并跳过加载。

数据保存在当前 Windows 用户目录，**不在便携 EXE 旁**：

```text
%APPDATA%\brilliant-gems\save-v1.json
%APPDATA%\brilliant-gems\settings.json
```

## 本地开发

需要 Node.js 22.12 或更新版本、npm 10 或更新版本。Windows x64 用于打包便携 EXE。

```powershell
npm install
npm run dev
```

| 命令 | 用途 |
| --- | --- |
| `npm run typecheck` | TypeScript 检查 |
| `npm test` | Vitest 测试 |
| `npm run build` | 生成资源、检查类型并构建应用 |
| `npm run package` | 构建 Windows x64 便携版 |
| `npm run package:dir` | 构建未封装目录版 |

Electron 安装时会下载运行时；下载中断后可尝试 `npm rebuild electron`。本地便携包输出为 `release/璀璨宝石-Portable-x64.exe`，Release 下载文件使用英文名。

## 代码与测试

- `src/game/`：规则、数据、随机数状态、AI 和存档校验。
- `src/main/`、`src/preload/`：窗口、IPC、设置和存档。
- `src/renderer/`：React 界面、声音和视觉资源。
- `scripts/generate-assets.mjs`：生成图标与位图资源。
- `tests/`：卡牌数据、规则、AI 对局和存档测试。

规则由 `applyMove` 校验并产生新状态，随机数状态随存档保存。现有测试覆盖筹码配置、取牌与购牌、贵族、终局、AI 合法对局，以及损坏和未来版本存档。

Electron 启用上下文隔离与渲染器沙箱，关闭 Node.js 集成；界面通过 preload 接口访问设置、存档和窗口操作。
